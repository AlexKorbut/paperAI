# london-chronicle — Font Downloads

All fonts are released under the SIL Open Font License 1.1 (OFL-1.1).

Run `python scripts/fetch_fonts.py --theme london-chronicle` from the
morning-paper/ directory to fetch these automatically, or download manually from
the Google Fonts link below.

Expected files (names must match `theme.toml`):

- `IMFellEnglish-Regular.woff2`, `IMFellEnglish-Italic.woff2`

## IM Fell English

A revival of the 17th–19th century Fell types (a Caslon-adjacent English old-style
roman), used here for the engraved masthead, the small-caps section heads and the
dense justified body — giving the authentic Georgian letterpress texture of the
1759 evening post. The body is set larger than the ~7pt original for readability.

- License: OFL-1.1
- https://fonts.google.com/specimen/IM+Fell+English

## Note

The renderer warns (but does not fail) if font files are absent; system serif
fallbacks (Georgia, Times New Roman) are used instead.
